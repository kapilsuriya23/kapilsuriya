- Delivers progressive AI hints → algorithm explanation → complexity analysis → full solution
- Sub-100ms UI response with a dark glassmorphism interface and multi-language support

#### 💰 DebtBook — Full-Stack Debt Management Mobile App
`Flutter` `Riverpod` `Node.js` `Express.js` `MongoDB Atlas` `JWT` `GoRouter`
- Digitizes retail debt tracking with secure multi-user, biometric-authenticated access
- 10+ JWT-authenticated REST APIs with role-based access control and real-time balance recalculation
- Deployed on Render with a keep-alive cron strategy to eliminate cold-start latency

- Analytics dashboard with 4 visualizations powered by MongoDB aggregation pipelines
- Automated deadline reminders via email (Brevo SMTP + node-cron); deployed on Vercel + Render
- 🔗 [Live Demo](https://internship-tracker-seven-pied.vercel.app)
